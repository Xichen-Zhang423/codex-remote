# 远程连接与 Cloudflare 中转

Codex Remote 可以直接使用 Cloudflare Quick Tunnel。Quick Tunnel 域名会变化；中转 Worker 的作用是把“设备 ID → 当前隧道基础 URL”暂存到 KV，让已配对手机先查询最新地址。

中转只保存当前隧道基础 URL 和更新时间，不保存或发布手机 token，也不接触 Codex 登录信息、提示、任务文件或聊天记录。

## 安全边界

- Worker 只接受规范的 `https://*.trycloudflare.com` 基础 URL。
- KV 记录只包含基础 URL、设备 ID 和更新时间，并设置过期时间。
- 手机访问 token 不发布到 Worker。
- 发布密钥只存在于 Worker secret 与电脑端 `%LOCALAPPDATA%\CodexRemote\config.json`。
- Worker 的读取接口是公开的；真正的访问控制仍由 Codex Remote token 完成。

## 部署 Worker

1. 在 Cloudflare 控制台创建 Worker。
2. 创建一个 KV namespace，并以变量名 `RZ` 绑定到 Worker。
3. 将 `cloudflare-worker/rendezvous.js` 作为 Worker 代码部署。
4. 添加加密 secret `PUBLISH_SECRET`，值使用密码管理器生成。
5. 可选设置文本变量：
   - `DEVICE_ID`：例如 `YOUR_DEVICE_01`，用于限制一个 Worker 只接收该设备。
   - `RENDEZVOUS_TTL_SECONDS`：60 到 86400；默认 300。
6. 记下 Worker 的 HTTPS 基础地址，例如 `https://your-worker.example.workers.dev`。

不要把真实 secret 写进 Worker 源码或文档。

## 配置电脑端

先启动一次生成 `%LOCALAPPDATA%\CodexRemote\config.json`，停止服务后填写：

```json
{
  "rendezvous": {
    "url": "https://your-worker.example.workers.dev",
    "secret": "CHANGE_ME_WITH_RANDOM_SECRET",
    "deviceId": "YOUR_DEVICE_01"
  }
}
```

保留文件中已有的 `port`、`token`、`cwd`、`model` 和 `effort` 字段。`deviceId` 必须由 8–64 位字母、数字、下划线或连字符组成；若 Worker 设置了 `DEVICE_ID`，两边必须完全一致。

也可以在启动前设置环境变量：

```powershell
$env:CODEX_REMOTE_RENDEZVOUS_URL="https://your-worker.example.workers.dev"
$env:CODEX_REMOTE_RENDEZVOUS_SECRET="CHANGE_ME_WITH_RANDOM_SECRET"
$env:CODEX_REMOTE_DEVICE_ID="YOUR_DEVICE_01"
.\start.bat
```

## 验证

1. 启动后自动打开桌面控制台，默认公网。等待公网隧道 ready 后，确认主卡显示公网二维码。
2. 中转发布成功后，访问下面的公开读取地址：

   ```text
   https://your-worker.example.workers.dev/current?deviceId=YOUR_DEVICE_01
   ```

3. 响应应只包含 `url` 与更新时间，不应包含 token、发布密钥或聊天内容。
4. 扫描桌面控制台主卡的公网二维码并保存连接。局域网连接不会默认生成；仅在同一 Wi-Fi 时展开“连接选项”，点击“显示局域网连接”后按需生成局域网二维码。
5. 重启服务使 Quick Tunnel 换址；手机应通过 `rz` 自动解析新地址。

## 常见问题

- **读取返回 404**：还没有成功发布，记录已过期，或设备 ID 不一致。
- **发布返回 401**：电脑端 secret 与 Worker 的 `PUBLISH_SECRET` 不一致。
- **发布返回 403**：Worker 的 `DEVICE_ID` 与电脑配置不同。
- **服务显示隧道离线**：先暂时禁用中转，仅检查 `cloudflared` 是否能建立 Quick Tunnel。
- **手机仍连旧地址**：重新扫描桌面控制台的公网二维码以保存含正确 `rz` 的连接，或在设置中清除旧后端。

中转不是代理，手机仍直接访问当前隧道。它也不是凭据保险箱，不能用来存 token。
