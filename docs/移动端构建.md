# 移动端安装与构建

三种平台共用 `public/` 中的同一套 Web UI。先运行 `npm run verify`，再构建移动端，避免把语法错误打进安装包。

Android 仅交付自用 Debug APK，并通过 GitHub Actions 复现构建；HarmonyOS NEXT 由使用者在 DevEco Studio 手工配置签名；iPhone / iPad 仅交付 Safari PWA。

## PWA（Android 与 iPhone / iPad）

1. 用 HTTPS 隧道二维码打开 Codex Remote。
2. Android Chrome：菜单 → **安装应用** 或 **添加到主屏幕**。
3. iPhone / iPad Safari：分享 → **添加到主屏幕**。

PWA 缓存的是应用外壳，不缓存 Codex 登录凭据。后端连接信息保存在设备本地；更换 token 后应重新配对。

## Android APK（GitHub Actions）

`app-android/` 使用 Capacitor 8.4.1，应用 ID 为 `com.codex.remote`，显示名为 `Codex Remote`。云构建使用 Node.js 22；步骤如下：

1. 把 `codex-remote/` 单独作为 GitHub 仓库根目录。
2. 确认 `.github/workflows/build-apk.yml` 位于该仓库根目录下。
3. 在 **Actions → Build Codex Remote APK** 手动运行，或修改 `public/**`、`app-android/**` 后推送。
4. 构建完成后下载名为 `codex-remote-apk` 的 Artifact。
5. 解压得到 `app-debug.apk`，传到手机并允许该来源安装。

Debug APK 使用自动生成的调试签名，只适合自用，不是应用商店产物。本仓库不提供 release keystore、正式签名配置或商店发布流程。

本机已有 Android SDK 时可参考 `app-android/README.md` 手动构建。

## HarmonyOS NEXT

HarmonyOS NEXT 不运行 APK。使用 DevEco Studio 建立 Bundle `com.codex.remote`，把 `app-harmony/Index.ets` 与权限片段放入工程，再运行：

```powershell
.\app-harmony\copy-web-to-rawfile.ps1 -Project "D:\DevEcoProjects\CodexRemote"
```

随后在 DevEco Studio 用自己的华为开发者证书手工完成签名配置、连接手机并运行。完整步骤见 [HarmonyOS NEXT 教程](../app-harmony/使用教程-鸿蒙NEXT.md)。

### 产出中心发布检查

Android 的 Capacitor 命令必须在 `app-android/` 中运行。以下命令从仓库根目录进入包装目录；首次没有 `android/` 平台时先创建平台，每次都同步当前 Web 资源，并且即使命令失败也会返回仓库根目录：

```powershell
Push-Location app-android
try {
  npm ci --no-audit --no-fund
  if (-not (Test-Path android)) {
    npx cap add android
  }
  npx cap sync android
} finally {
  Pop-Location
}
```

1. 运行 `node scripts/sync-web-vendor.mjs --check`，确认本地 PDF.js 与锁定版本一致。
2. 运行上面的 Android 同步命令，确认 `artifact-ui.js` 和 `vendor/pdfjs/` 位于最终 assets。
3. HarmonyOS 构建前重新运行 `copy-web-to-rawfile.ps1`，确认 PDF worker 被递归复制。
4. PWA 发布时提升 Service Worker cache 名称；iOS 仅按 PWA 安装说明交付。

每次 `public/` 更新后，必须重新运行 Android 工作流和 HarmonyOS 资源同步。同步范围包括 `artifact-ui.js`、`vendor/pdfjs/pdf.min.mjs`、`vendor/pdfjs/pdf.worker.min.mjs` 与 `public/icons/`；缺少 PDF worker 时不得交付安装包。

Android 工作流只生成 Debug APK。iPhone / iPad 只使用 Safari PWA，本项目不创建 Xcode 工程。

## 更新策略

- PWA：重新打开页面；若版本未更新，清除该站点缓存后重开。
- APK：每次 UI 更新后重新运行工作流并覆盖安装新 Debug APK。
- HarmonyOS NEXT：重新复制 `public/`、编译并覆盖安装。

包装应用不应内置真实 token。Harmony 壳如需免扫码，可以在本地构建前填占位常量，但填过真实值的文件绝不能提交。
