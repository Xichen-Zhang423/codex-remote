# Codex Remote 使用教程

本文按“本机验证 → 手机连接 → 批准 → 远程连接 → 安全停止”的顺序操作。命令均在 `codex-remote` 目录执行。

## 首次启动

1. 安装 Node.js 18 或更高版本，重新打开 PowerShell。
2. 完成本机 Codex 登录（依赖由启动器自动安装）：

   ```powershell
   npx --yes --package @openai/codex@0.144.1 codex login
   npx --yes --package @openai/codex@0.144.1 codex login status
   ```

3. 双击 `start.bat`。首次启动会在 `%LOCALAPPDATA%\CodexRemote\config.json` 创建本机专用配置，不要提交或分享。源码目录不需要写权限。
4. 终端先打印局域网地址和二维码；Quick Tunnel 就绪后再打印 `Tunnel base URL` 公网地址和第二个二维码。出门使用必须扫描第二个。
5. 若只想本机验证，在电脑浏览器打开终端地址；只用局域网时可设置 `NO_TUNNEL=1`。

## 手机首次连接

1. 打开手机系统相机或 Codex Remote 内的扫码器。
2. 扫描当前终端二维码。隧道地址可能随重启变化，但二维码中的私密访问 token 会持续有效，直到你在电脑端主动轮换。
3. 连接成功后，状态点变为在线；连接资料保存在当前浏览器/App 本地。
4. 在设置中确认工作目录。目录浏览器只能在后端允许的路径内操作。
5. 在输入框发送一个不调用工具的简单请求，确认能收到流式回复。

手机链接一旦保存，页面会清掉地址栏中的 token。仍不要把二维码、浏览器站点数据或导出的连接配置交给他人。

## 开始工作

- “新对话”创建独立线程。
- 历史抽屉可以搜索、打开、重命名和归档线程。
- 设置中可以更改工作目录、模型和推理强度。
- 图片按钮可添加截图或照片；单次最多 4 张。后端仅为当前回合建立临时文件。
- 停止按钮会中断当前回合，排队中的下一条提示会按界面状态处理。
- 每轮完成后先查看“本次产出”；历史产出抽屉会保留文件元数据，并为确认文件建立不可变副本。

切换仓库前先确认路径。移动端看到的命令、差异和工具活动都属于当前线程与当前工作目录。

## 处理批准

默认每个敏感动作都出现批准卡片：

- 命令执行：检查完整命令、工作目录和理由。
- 文件修改：检查目标路径与差异摘要。
- 网络或权限：检查目标、范围和持续时间。
- 用户输入：只选择你理解的答案。

“允许一次”只处理这一项；“拒绝”把拒绝结果交回 Codex。会话自动批准只在当前服务进程存活期间生效，并且只自动处理后端明确判定为安全的合格项。服务退出、崩溃、更新或电脑重启都会恢复逐项批准。

不确定时拒绝，再让 Codex 解释它为什么需要这一步。

## 查看和控制电脑屏幕

1. 把可信的 `ffmpeg.exe` 放在项目根目录后重启服务。
2. 打开屏幕查看器；服务会周期性生成新的临时 JPEG，发送后删除。
3. 轻点为单击，长按为右键，双指缩放用于查看；键盘抽屉发送文字和受支持的组合键。

高 DPI 坐标由电脑端换算。若截图缺角或点击偏移，先确认服务实际使用 `ffmpeg`，然后重新启动；不要通过降低显示缩放来掩盖问题。

## 公网使用与免重复扫码

Quick Tunnel 适合临时公网访问，但域名可能在服务重启后改变。希望手机始终使用同一个入口时，部署 `cloudflare-worker/rendezvous.js`，配置 KV、发布密钥和设备 ID，再把 Worker 基础 URL 写入 `%LOCALAPPDATA%\CodexRemote\config.json`。详见 [远程连接与中转](./远程连接与中转.md)。

中转仅返回当前隧道基础 URL。手机访问 token 留在二维码/设备本地，发布密钥只留在电脑配置和 Worker secret 中。

出门前关闭手机 Wi-Fi，用手机流量打开一次公网入口。电脑必须保持开机、联网并保持 Windows 用户登录；Codex Remote 运行时会阻止系统自动睡眠但允许屏幕熄灭。关闭启动窗口或停止服务后，防睡眠请求和公网隧道都会立即结束。

## 安装到手机

- Android：PWA 可直接添加到桌面；需要 APK 时使用 GitHub Actions 生成 `codex-remote-apk`。
- iPhone/iPad：通过 HTTPS 在 Safari 打开，选择“添加到主屏幕”。
- HarmonyOS NEXT：按 [HarmonyOS NEXT 教程](../app-harmony/使用教程-鸿蒙NEXT.md) 在 DevEco Studio 构建签名壳。

详见 [移动端构建](./移动端构建.md)。

## 正常停止与游戏前处理

平时可在启动窗口按 `Ctrl+C`，让服务关闭自己拥有的 App Server 和隧道子进程。也可双击 `停止遥控.bat`；它依据启动器和用户运行时的绝对命令行定位服务，不会按名称结束所有 Node 或桌面应用。

运行带反作弊系统的游戏前，必须停止遥控、取消开机自启并重启电脑一次。不要尝试隐藏输入模拟或屏幕抓取。

## 更新

1. 先停止服务。
2. 更新项目文件。
3. 开发者可在可写工作副本运行 `npm ci` 和 `npm run verify`；普通用户无需手动安装依赖。
4. 重新启动；启动器会为新内容哈希准备独立运行时。确认界面已刷新，必要时清除旧 PWA 缓存。

更新或重启后，会话自动批准保持关闭。

## 故障排查顺序

1. 电脑端：`node --version`、`npx --yes --package @openai/codex@0.144.1 codex login status`、`npm run verify`。
2. 服务端：看启动窗口第一条明确错误，确认端口和工作目录。
3. 局域网：先设置 `NO_TUNNEL=1` 测试同一 Wi-Fi。
4. 隧道：确认二进制与网络，再检查中转发布状态。
5. 手机端：重新扫码；清除旧站点缓存；检查系统相机、通知和麦克风权限。
6. 屏幕端：安装 `ffmpeg`，重启服务后再测试，避免反复触发安全软件。

以下三类问题可以直接按对应路径处理：

- 找不到 `ffmpeg` 或 `cloudflared`：把可信二进制放在 `%LOCALAPPDATA%\CodexRemote\bin`、独立仓库根目录，或加入系统 `PATH`；程序不会搜索父目录。
- 二维码生成失败：从本机面板复制连接地址；二维码失败不会停止服务。
- 手机上看不到任务文件：打开当前任务的“本次产出”卡片或历史产出抽屉；重新连接后产出元数据会恢复。
