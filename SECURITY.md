# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 0.1.x | Yes |
| Earlier versions | No |

## Reporting a vulnerability

Use this repository's **GitHub Security Advisories** flow: **Security → Advisories → Report a vulnerability**. Do not disclose an exploitable issue in a public issue.

Remove connection tokens, QR codes, `config.json`, credentials, personal paths, prompt content, screenshots, and unredacted logs before submitting evidence. Include the affected version, Windows version, reproduction steps, impact, and the smallest safe diagnostic excerpt.

Codex Remote never needs a Codex credential copied into a report. Rotate the phone token and rendezvous secret if either may have been exposed.
